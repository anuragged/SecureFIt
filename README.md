# SecureFit: AI-Powered Fitness Companion

SecureFit is a modern, full-stack web application designed to be a personal fitness companion. Track your fitness metrics, get AI-powered diet recommendations, and manage your personal profile all in one place.

---

## 🚀 Features

- **Secure User Authentication** – Robust user sign-up and login functionality.  
- **Personalized User Profiles** – Manage physical metrics (height, weight, DOB) and fitness goals.  
- **Real-time Fitness Dashboard** – Key statistics from the last 7 days, including calories burned, active time, and workouts.  
- **Live Activity Feed** – Updates on your most recent workout sessions in real-time.  
- **AI-Powered Diet Plans** – Personalized 1-day diet plans generated with AI based on your profile and goals.  
- **Optimistic UI Updates** – Immediate UI feedback for a seamless experience.  
- **Advanced Error Handling** – Global error system capturing and displaying detailed errors for rapid debugging.  

---

## 🛠 Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)  
- **Language:** [TypeScript](https://www.typescriptlang.org/)  
- **Frontend:** [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)  
- **UI Components:** [ShadCN UI](https://ui.shadcn.com/)  
- **Generative AI:** [Google Genkit](https://firebase.google.com/docs/genkit) with Gemini 2.5 Flash model  
- **Form Management:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)  
- **Data Fetching:** Custom React hooks with memoization for performance

## ⚡ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/en/) (v20+)  
- [npm](https://www.npmjs.com/)  

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/securefit-app.git
cd securefit-app
````

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Open your browser at [http://localhost:9002](http://localhost:9002) to view the app.
